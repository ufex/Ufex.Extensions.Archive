# Ufex.Extensions.Archive

A collection of [Ufex](https://github.com/ufex) C# plugin projects for archive file formats. 

## Plugins

| Project | Format(s) | Description |
|---------|-----------|-------------|
| **CAB** | Microsoft CAB | Microsoft Cabinet archives. Parses cabinet headers, folder and file entries, and compression methods. |
| **ISCAB** | InstallShield CAB | InstallShield Cabinet archives. Parses cabinet headers, folder and file entries, and compression methods. |
| **SGIInst** | SGI inst | SGI installation archives. Parses archive headers, file entries, and compression methods. |
| **TAR** | TAR | TAR archives. Parses header blocks, file entries, and supports various TAR formats (e.g., USTAR, GNU). |
